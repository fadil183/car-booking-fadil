CAR BOOKING API DOCUMENTATION
=============================

Base URL      : http://localhost:8080
Framework     : Echo v4
Content-Type  : application/json (semua request memakai body JSON)

CATATAN UMUM
------------
- Semua route memakai method POST.
- Tidak ada middleware/token. Route yang butuh identitas user (/topup, /books,
  /history) mengirim "email" dan "password" di body, lalu diverifikasi server.
- Semua response error berformat:
      {"message": "<pesan error>"}
- Password disimpan dalam bentuk hash SHA-256 + salt acak ("salt$hash").
- Format tanggal: YYYY-MM-DD.

DAFTAR ROUTE
------------
  1. POST /register   Mendaftarkan user baru
  2. POST /login      Login (verifikasi email & password)
  3. POST /topup      Menambah deposit user
  4. POST /rent       Daftar mobil yang tersedia (availability > 0)
  5. POST /books      Memesan mobil
  6. POST /history    Riwayat top up & booking user


======================================================================
1. POST /register
======================================================================
Deskripsi : Membuat user baru. Deposit awal 0.

Request body:
  email     string   wajib   Email unik, spasi di awal/akhir dibuang
  password  string   wajib   Tidak boleh kosong / hanya spasi

Contoh request:
  {
    "email": "user@example.com",
    "password": "password123"
  }

Response:
  201 Created
    {"message": "new user has been created"}

  400 Bad Request
    {"message": "invalid request body"}
    {"message": "email and password are required"}

  500 Internal Server Error
    {"message": "failed to process password"}
    {"message": "failed to create user"}      (mis. email sudah terdaftar)


======================================================================
2. POST /login
======================================================================
Deskripsi : Memeriksa email dan password. Tidak menghasilkan token.

Request body:
  email     string   wajib
  password  string   wajib

Contoh request:
  {
    "email": "user@example.com",
    "password": "password123"
  }

Response:
  200 OK
    {"message": "login success"}

  400 Bad Request
    {"message": "invalid request body"}
    {"message": "email and password are required"}

  401 Unauthorized
    {"message": "invalid email or password"}
    (pesan sama untuk email tidak ditemukan dan password salah)

  500 Internal Server Error
    {"message": "failed to process login"}


======================================================================
3. POST /topup
======================================================================
Deskripsi : Menambah deposit_amount user, dan mencatat satu baris
            bertipe TOPUP di tabel history.

Request body:
  email     string   wajib
  password  string   wajib
  amount    number   wajib   Harus > 0

Contoh request:
  {
    "email": "user@example.com",
    "password": "password123",
    "amount": 500000
  }

Response:
  200 OK
    {
      "message": "top up success",
      "deposit_amount": 500000
    }
    deposit_amount = saldo user setelah top up.

  400 Bad Request
    {"message": "invalid request body"}
    {"message": "email and password are required"}
    {"message": "amount must be greater than 0"}

  401 Unauthorized
    {"message": "invalid email or password"}

  500 Internal Server Error
    {"message": "failed to process top up"}
    {"message": "failed to top up deposit"}


======================================================================
4. POST /rent
======================================================================
Deskripsi : Mengambil semua mobil dengan availability > 0,
            diurutkan berdasarkan car_id.

Request body: tidak ada (kosong).

Response:
  200 OK
    {
      "message": "available cars",
      "total": 2,
      "cars": [
        {
          "car_id": 1,
          "name": "Toyota Avanza 1.5 G",
          "transmission": "AT",
          "availability": 1,
          "rental_cost": 450000,
          "category": "MPV"
        }
      ]
    }
    Jika tidak ada mobil tersedia: "total": 0 dan "cars": [].

    Keterangan field cars:
      car_id        ID mobil
      name          Nama mobil
      transmission  Jenis transmisi (AT / MT / EV)
      availability  Jumlah unit tersedia
      rental_cost   Biaya sewa per hari
      category      Kategori mobil (MPV, SUV, EV, LCGC)

  500 Internal Server Error
    {"message": "failed to get available cars"}


======================================================================
5. POST /books
======================================================================
Deskripsi : Memesan mobil untuk periode [start_date, end_date).
            end_date tidak dihitung sebagai hari sewa.
            Total biaya = rental_cost x jumlah hari.
            Dalam satu transaksi database, server akan:
              - mengurangi availability mobil sebanyak 1
              - memotong deposit user sebesar total biaya
              - menyimpan data ke tabel books
              - mencatat satu baris bertipe BOOKING di tabel history
            Jika salah satu langkah gagal, semuanya dibatalkan.

Request body:
  email       string   wajib
  password    string   wajib
  car_id      number   wajib   ID mobil (> 0)
  start_date  string   wajib   YYYY-MM-DD, tidak boleh tanggal lampau
  end_date    string   wajib   YYYY-MM-DD, harus setelah start_date

Contoh request:
  {
    "email": "user@example.com",
    "password": "password123",
    "car_id": 1,
    "start_date": "2026-10-10",
    "end_date": "2026-10-13"
  }

Response:
  201 Created
    {
      "message": "booking success",
      "book_id": 1,
      "car_id": 1,
      "start_date": "2026-10-10",
      "end_date": "2026-10-13",
      "days": 3,
      "total_cost": 1350000
    }

  400 Bad Request
    {"message": "invalid request body"}
    {"message": "email and password are required"}
    {"message": "car_id is required"}
    {"message": "start_date must use format YYYY-MM-DD"}
    {"message": "end_date must use format YYYY-MM-DD"}
    {"message": "start_date cannot be in the past"}
    {"message": "end_date must be after start_date"}

  401 Unauthorized
    {"message": "invalid email or password"}

  402 Payment Required
    {"message": "insufficient deposit, please top up"}

  404 Not Found
    {"message": "car not found"}

  409 Conflict
    {"message": "car is not available"}      (availability = 0)

  500 Internal Server Error
    {"message": "failed to process booking"}
    {"message": "failed to book car"}


======================================================================
6. POST /history
======================================================================
Deskripsi : Mengambil riwayat top up dan booking milik user,
            diurutkan dari yang terbaru.

Request body:
  email     string   wajib
  password  string   wajib

Contoh request:
  {
    "email": "user@example.com",
    "password": "password123"
  }

Response:
  200 OK
    {
      "message": "user history",
      "email": "user@example.com",
      "total": 2,
      "history": [
        {
          "history_id": 2,
          "type": "BOOKING",
          "book_id": 1,
          "car_id": 1,
          "car_name": "Toyota Avanza 1.5 G",
          "amount": 1350000,
          "balance_after": 50000,
          "description": "Car booking 2026-10-10 to 2026-10-13 (3 days)",
          "created_at": "2026-10-09T18:10:00+07:00"
        },
        {
          "history_id": 1,
          "type": "TOPUP",
          "book_id": null,
          "car_id": null,
          "car_name": null,
          "amount": 500000,
          "balance_after": 500000,
          "description": "Deposit top up",
          "created_at": "2026-10-09T18:05:00+07:00"
        }
      ]
    }
    Jika belum ada riwayat: "total": 0 dan "history": [].

    Keterangan field history:
      history_id     ID baris riwayat
      type           TOPUP atau BOOKING
      book_id        ID booking (null untuk TOPUP)
      car_id         ID mobil (null untuk TOPUP)
      car_name       Nama mobil (null untuk TOPUP)
      amount         Nominal transaksi
      balance_after  Saldo deposit setelah transaksi
      description    Keterangan transaksi
      created_at     Waktu transaksi

  400 Bad Request
    {"message": "invalid request body"}
    {"message": "email and password are required"}

  401 Unauthorized
    {"message": "invalid email or password"}

  500 Internal Server Error
    {"message": "failed to process history"}
    {"message": "failed to get history"}


TABEL DATABASE
--------------
  users    : userID, email, password, deposit_amount
  cars     : carID, name, transmission, availability, rental_cost, category
  books    : bookID, carID, userID, booking_period, created_at, updated_at
  history  : historyID, userID, bookID, carID, type, amount, balance_after,
             description, created_at
  (definisi lengkap ada di ddl.sql)
